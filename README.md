## ⭐ Featured project

### [react-smart-copy](https://github.com/suprabhat02/react-smart-copy)

A headless React primitive for the **whole moment around the clipboard** — not just `writeText()`.

[![npm version](https://img.shields.io/npm/v/react-smart-copy?style=flat-square&color=CB3837)](https://www.npmjs.com/package/react-smart-copy)
[![downloads](https://img.shields.io/npm/dm/react-smart-copy?style=flat-square)](https://www.npmjs.com/package/react-smart-copy)
[![bundle size](https://img.shields.io/bundlephobia/minzip/react-smart-copy?style=flat-square)](https://bundlephobia.com/package/react-smart-copy)
![coverage 100%](https://img.shields.io/badge/coverage-100%25-brightgreen?style=flat-square)
![WCAG 2.1 AA](https://img.shields.io/badge/WCAG-2.1%20AA-blue?style=flat-square)

- 🧠 **State machines** (idle → copying → copied → error → retry) with thin React bindings.
- 📊 **Table copy** that pastes into Excel and Google Sheets as real cells — works with AG Grid and TanStack Table.
- 🎛️ **Advanced controls** — `useCopyInterceptor`, `useDragCopy` and SVG/DOM-to-PNG capture.
- 🛡️ **Production ready** — SSR-safe, ~3.2 kB `useCopy`, zero dependencies, 100% test coverage, WCAG 2.1 AA verified.

📖 **[Docs & live demos →](https://suprabhat02.github.io/react-smart-copy)**
